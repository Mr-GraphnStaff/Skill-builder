# Public wiki maintenance

The canonical user documentation is the [SkillJetty wiki](https://github.com/Mr-GraphnStaff/Skill-builder/wiki).
The release coordinator owns keeping it current for both channels.

- At a user-visible incident or release start, publish an accurately dated pending notice.
- Before declaring delivery complete, verify the public version/channel flags and package, then update Home, Release Channels, Release Notes and affected Troubleshooting pages.
- Verify channel-switch availability and preview > stable ordering, not just historical versions. Do not infer either PC's installed state from the catalog.
- Preserve earlier release notes, keep internal records/credentials/private data out, and record the published wiki commit in the project delivery record.

See the wiki's Maintainer Update Procedure for editing and readback steps. A source README update alone does not update the wiki.
