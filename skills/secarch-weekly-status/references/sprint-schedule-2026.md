# Sprint Schedule 2026

Use this file when the workflow needs sprint context.

## Rules

- Quarter label comes from the sprint start date.
- Sprint day formula: `today - sprint_start + 1`.
- Days remaining formula: `sprint_end - today`.
- Sprint week mapping: day 1-7 = week 1, day 8-14 = week 2, day 15-21 = week 3.
- Prefer Jira `customfield_10006` if it is available and reliable. Use this table as fallback.
